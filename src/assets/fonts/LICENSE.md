# Fuentes incluidas

Todas se distribuyen bajo la **SIL Open Font License 1.1** (https://openfontlicense.org), que permite
usarlas, incrustarlas y redistribuirlas junto con software. Los archivos `.woff2` proceden de los paquetes
de Fontsource y contienen solo el subconjunto latino.

| Familia | Autoría | Uso en la app |
| --- | --- | --- |
| Fraunces (variable: wght, opsz, SOFT, WONK) | The Fraunces Project Authors | Títulos, apodos, presentación |
| Manrope (variable: wght) | The Manrope Project Authors | Texto de interfaz |
| Bricolage Grotesque (variable: wght) | The Bricolage Grotesque Project Authors | Títulos del estilo Maximalismo |
| Dancing Script (variable: wght) | The Dancing Script Project Authors | Firma |
